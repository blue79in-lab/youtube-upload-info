승인된 YouTube 채널의 영상 업로드·공개 예약·썸네일 관리와 댓글 검토용 브리핑, 채널 실적 분석을 지원하는 로컬 운영 도구입니다.

blue79in이 개인 운영 계정으로 관리합니다. 회사 공식 앱 또는 Google·YouTube의 공식 제품이라고 표시하지 않습니다.

주요 기능

  • 사용자가 준비한 영상과 제목·설명·태그를 YouTube에 업로드하고 공개 예약과 썸네일 설정을 지원합니다.
  • 공개 댓글·답글 및 접근 가능한 검토대기 표본을 조회하여 운영자가 검토할 보고서를 만듭니다. 조회 상한이 있어 전체 댓글 검사 결과는 아닙니다.

접근과 운영

Google OAuth에서 사용자가 직접 허용한 채널과 권한으로 공식 YouTube API Services를 이용합니다. Google 로그인·최종 동의는 Google 화면에서 진행합니다. 앱 전체는 읽기 전용이 아니며, 업로드와 썸네일 설정은 YouTube에 변경을 수행합니다. 현재 댓글 브리핑 수집기는 조회만 수행하고 댓글을 자동 삭제하거나 답글을 작성하지 않습니다.

인증 정보와 운영 자료는 로컬 파일에 저장됩니다. 승인된 브리핑 업무에서는 댓글·분석 결과가 Codex/ChatGPT 대화로 전달될 수 있습니다. 자세한 범위와 확정된 보관·삭제 기준는 개인정보처리방침을 확인하세요.
